# Contributing and reporting issues

MustardTube is a community beta maintained by PapaZolaRis. Feedback is welcome!
Use **Issues** for bug reports and feature proposals. For a bug, provide device,
muOS version, tab, exact reproduction steps, expected/actual result, screenshots,
and a redacted log if available. **Never share private media URLs, tokens,
credentials, or personal viewing/search history.**

Test changes on a real H700 handheld; no claim of compatibility is made for
other devices, or for Goose/Jacaranda versions of muOS.

Third-party code/assets must retain their copyright and licence notices.
See `docs/BUILDING.md` before preparing a new installer.
