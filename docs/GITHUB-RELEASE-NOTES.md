# MustardTube v0.9.11 Beta 2 — YouTube + Internet Radio for muOS Andromeda

**Developer:** PapaZolaRis  
**Status:** Public testing / prerelease  
**Devices:** RG35XX Plus and RG35XX SP  
**Firmware:** muOS 2606.0 Andromeda  
**No PortMaster required.**

## Included

- Home video discovery categories: Explore, Popular, For You, Music, Gaming, Tech
- Real thumbnails for Home and Search
- Search pagination up to 40 results
- Internet Radio country browsing with alphabetical lists, country flags, optional station logos, favourites and paging
- Hold D-pad Up/Down for Radio scrolling; Left/Right to jump seven rows
- Scrollable About / User Guide with controller guide, notices and troubleshooting
- Themes, Clear Cache and Clear Viewing History in Settings
- Stock Wasabi media playback; 360p default, 480p selectable and experimental 720p

## Install

Copy the attached `.muxapp` to the SD card `ARCHIVE` folder. Install with
**Applications → Archive Manager**, connect to Wi-Fi, then launch MustardTube.
Back up the existing `data` directory before replacing an older version.

## Limitations

Experimental recorded 720p **does not support seeking**. Live streams are
also **not seekable**. Some streams/stations may be incompatible or offline.
No offline video downloader or automatic CPU governor setting is included.
The prebuilt package is for stock Andromeda on the target H700 devices.
