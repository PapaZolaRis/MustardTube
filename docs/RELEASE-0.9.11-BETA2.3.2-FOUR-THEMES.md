# Beta 2.3.2 — Four themes and consistent header branding

Source-only UI release candidate. No multimedia/runtime/installer-size optimization is included.

Theme identities: Midnight / Black Gold, Forest / Botanical Club, Paper / Champagne Linen, Acid Bloom / Neon After Hours.

Four equal-size Settings options arranged 2×2; D-pad moves according to the grid, A applies. Saved theme settings continue to accept the previous three names. A new `acidbloom` setting is added. The PNG header uses a transparent mascot silhouette instead of a black or yellow tile.

Hardware verification: test all pages in all four themes, ensure launch glyph, 360p/480p seeking, 720p/1080p playback, live streams, radio, volume mixing, sleep on SP, and return from Wasabi. Compare startup against Beta 2.3.0 baseline.

Installer-size reductions, binary stripping, runtime changes, and new features are deferred until the UI build is verified.
