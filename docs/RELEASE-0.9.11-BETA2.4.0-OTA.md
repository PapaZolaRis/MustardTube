# MustardTube v0.9.11 Beta 2.4.0 — Candidate notes

- Retains the four Beta 2.3.2 themes and equal-size Home/Search video cards.
- Updated header tagline: WATCH · LISTEN · PLAY.
- Added a controller-operated Settings → Software updates page.
- Opt-in Stable/Beta channel, GitHub Releases detection, verified archive download.
- Uses stock muOS Archive Manager for manual installation after download.
- No third-party runtime upgrades, new UI framework, network polling daemon or
  automatic changes to installed application files.
- Preserves existing YouTube resolution handling, livestreams, radio,
  Wasabi handoff, audio mixing, favourites, cache and navigation paths.

**Status:** Development candidate. Needs Ubuntu ARM64 build, two-device smoke
and OTA tests; licensing audit remains open. Not a public stable release.
