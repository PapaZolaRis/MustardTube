# MustardTube v0.9.11 Combined Beta 2 — Radio and About UX fixes

- Country names sorted alphabetically, not by station count.
- Station names sorted alphabetically at source and after each page.
- Full lists remain paginated (Radio Browser: 20 per network request, up to 80 cached stations per country).
- Country and station heading no longer obscured by list rows. Seven rows fit beneath the title.
- Radio D-pad held UP/DOWN repeats after 320ms at 85ms intervals (gamepad), and SDL keyboard auto-repeat is supported.
- Radio LEFT/RIGHT jumps seven rows. Selection always remains in list bounds.
- On-screen item counts and slim scroll indicators in Radio.
- About screen expanded into 100+ scrollable lines of installation instructions, control guide, limitations, privacy, troubleshooting, legal notice and licensing.
- About D-pad held UP/DOWN scrolls line by line; LEFT/RIGHT jumps one page.
- All original Wasabi playback integration is unchanged.

**Hardware status:** ARM64 build and host tests require validation on RG35XX Plus/SP before public distribution.
